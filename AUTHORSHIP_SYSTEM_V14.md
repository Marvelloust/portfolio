# V14 Authorship System

The portfolio no longer treats “technical-looking” as a substitute for authorship.

## The visual grammar

**Open → inspect → connect → verify → file.**

`[MO]` is the mechanism that opens and closes records. It appears in route retrieval, ownership, the archive aperture, navigation, and the closing footer state.

## Ownership taxonomy

- **PERSONAL BUILD** — independently owned build record.
- **DESIGN RECORD** — interface/product-design evidence; never disguised as shipped engineering.
- **TEAM CONTRIBUTION** — work completed inside Neegles; no implied sole ownership.

## Flagship grammars

- **SwiftSlot — time / constraint:** requests converge toward one canonical protected slot.
- **KoraGo — route / locality:** discovery becomes choice, route, and delivery.
- **Relay — context / review:** ticket context is assembled before a human-reviewed recommendation.
- **Stamp — authority / state:** request, authorization, decision, and audit are explicit states.
- **Fieldnote — offline / synchronization:** capture, queue, sync, and verification are first-class states.

## Restraint rule

Technical grids and labels are reserved for moments that communicate evidence, ownership, state, or motion. Quiet sections intentionally contain less decoration.
